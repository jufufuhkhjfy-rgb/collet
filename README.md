# Collet

楽天ROOMへの投稿を手伝う、Windows 用のツールです。

- 楽天市場のランキングから、選んだジャンルの人気商品を自動で探します
- 商品ごとに紹介文を用意します（PCで動くAI、Claude API、テンプレートのどれか）
- 紹介カード画像（1投稿3枚）を作れます
- Chrome 拡張機能「Collet ROOM アシスト」が、ROOMの投稿画面に紹介文と画像を入れます

**投稿を確定する「完了」ボタンは、毎回自分で押します。** 楽天ROOMには投稿用の公開APIがないため、ROOMへの投稿そのものは自動にしていません。

## 動かすのに必要なもの

- Windows 10 / 11
- [Python](https://www.python.org/downloads/) 3.10 以上（インストールのとき「Add python.exe to PATH」にチェック）
- Google Chrome
- 楽天会員のアカウント（楽天ウェブサービスのアプリIDを取るため）

## 1. ダウンロードする

**[ここを押すと Collet.zip がダウンロードされます](https://github.com/jufufuhkhjfy-rgb/collet/releases/latest/download/Collet.zip)**

ダウンロードした Collet.zip を右クリック →「すべて展開」で、好きな場所（デスクトップやドキュメントなど）に展開します。

## 2. セットアップする

展開したフォルダの **setup.bat** をダブルクリックします。

「Windows によって PC が保護されました」と出たときは、「詳細情報」→「実行」を押してください（ネットからダウンロードしたファイルに出る、いつもの確認です）。

- 必要な部品のインストール
- 設定ファイル `.env` の作成
- デスクトップへの「Collet」ショートカットの作成

が自動で進みます。最後に `.env` がメモ帳で開きます。

## 3. 楽天のアプリIDを設定する

1. [楽天ウェブサービス](https://webservice.rakuten.co.jp/) に楽天IDでログインして、「アプリID発行」を押す
2. 次のように入力する
   - アプリケーションタイプ：**API/バックエンドサービス**
   - 許可されたWebサイト：**自分の家のIPアドレス**（「IPアドレス 確認」で検索すると調べられます）
   - APIアクセススコープ：**楽天市場API** にチェック
3. 発行された「アプリケーションID」「アクセスキー」「アフィリエイトID」を `.env` に書き込んで保存する

```
RAKUTEN_APP_ID=アプリケーションID
RAKUTEN_ACCESS_KEY=アクセスキー
RAKUTEN_AFFILIATE_ID=アフィリエイトID
```

家のIPアドレスはときどき変わります。候補を集めるときに「接続を断られました（403）」と出たら、楽天ウェブサービスのアプリ設定で、IPアドレスを新しいものに書き換えてください。

**アクセスキーは人に見せないでください。** スクリーンショットにも写さないようにしてください。

## 4. 拡張機能を入れる

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押して、Collet フォルダの中の `extension` フォルダを選ぶ

## 5. 使う

1. デスクトップの **Collet** をダブルクリックする（専用のウィンドウが開きます）
2. 「投稿設定」で、ペースとジャンルを選ぶ
3. 右上の「今すぐ候補を集める」を押す
4. 「今日の投稿」で紹介文を読んで、必要なら書き直す
5. 「ROOMで開く」（または「まとめてROOMで開く」）を押す
6. ROOMの投稿画面で、紹介文と画像が入っているのを確認して「完了」を押す

ROOMには、ふだん使っている Chrome で先にログインしておいてください。

ウィンドウを閉じても、Collet は裏で動き続けます（自動の候補集めのため）。止めるときは、左下の「Collet を終了」を押します。

### 有料プランと利用キー

配っている Collet によっては、一部または全部の機能に「利用キー」（月額の有料プラン）が必要です。利用キーを買ったら、「投稿設定」の「有料プラン」に貼り付けてください。利用キーには期限があります。期限が切れたら、新しい利用キーを入れてください。

## 紹介文を書くAI（どれか1つ。なくても動きます）

なにも設定しないと、紹介文はテンプレートで作ります。

### PCで動くAI（無料・おすすめ）

1. [Ollama](https://ollama.com/) をインストールする
2. コマンドプロンプトで `ollama pull qwen2.5:7b` を実行する（約5GBのダウンロード）

グラフィックボード（VRAM 8GB くらい）があると速く動きます。

### Claude API（有料）

[Anthropic のコンソール](https://console.anthropic.com/) でAPIキーを作って、`.env` の `ANTHROPIC_API_KEY=` に入れます。Anthropic の利用条件（18歳以上など）を確認してから使ってください。

### 投稿者の紹介を変える

`.env` の `COLLET_PERSONA=` に、どんな人として紹介文を書くかを入れられます。

```
COLLET_PERSONA=一人暮らしの社会人で、北欧インテリアが好きな人
```

## 紹介カード画像

「今日の投稿」の「紹介カードを作る」で、1商品につき3枚の画像を作れます（商品・レビューと価格・おすすめポイント）。背景はAIで作った画像を同梱しているので、追加のインストールはいりません。

画像を付けた投稿では、紹介文の先頭に「※画像の背景はAIで作ったイメージです。」が自動で入ります。

### 部屋に置いた画像（上級者向け・任意）

商品写真を切り抜いて、AIで描いた部屋に合成する機能です。うまくいく商品は一部だけです。NVIDIA のグラフィックボードと、約10GBの空きが必要です。

```powershell
py -3.12 -m venv imggen\.venv
imggen\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu126
imggen\.venv\Scripts\python.exe -m pip install diffusers transformers accelerate safetensors pillow requests rembg onnxruntime
```

入れると「今日の投稿」に「部屋に置いた画像を作る」ボタンが出ます。この画像を付けた投稿には、紹介文の先頭に「※画像はAIで作ったイメージです。実際に使っている写真ではありません。」が自動で入ります。

## 使うときの注意

- **投稿する前に、紹介文を必ず読んでください。** AIは、商品説明にないことを書くことがあります。事実と違う紹介は、景品表示法などの問題になります
- 「使ってみた」「愛用中」など、実際に使っていない物の体験談は書かないでください（ステマ規制）
- AI画像の注意書きは消さないでください
- 短い時間に大量に投稿すると、スパムと見られることがあります。1日に数件〜10件くらいが目安です
- 楽天ROOM・楽天ウェブサービスの規約を守って使ってください。このツールを使ったことによるアカウントの停止などについて、作者は責任を負えません
- 未成年の人は、楽天ROOMで報酬を受け取る前に、保護者の同意をもらってください

## うまく動かないとき

- 動きの記録は `data/collet.log` にあります
- ROOMの画面が変わると、拡張機能が紹介文や画像を入れられなくなることがあります。そのときは `extension/room.js` を直す必要があります

## 中で使っているもの

- 見出しのフォント：[M PLUS Rounded 1c](https://fonts.google.com/specimen/M+PLUS+Rounded+1c)（SIL Open Font License 1.1。`assets/fonts/OFL.txt`）
- 紹介カードの背景：Stable Diffusion 1.5 で作った画像
- 楽天ウェブサービス（楽天市場ランキングAPI）

## API

Collet は `http://127.0.0.1:8765` で動いています。

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET / PUT | /api/settings | 設定の取得と変更 |
| GET | /api/status | 稼働状態、今日の投稿数、投稿待ちの件数 |
| POST | /api/start, /api/stop | 自動の候補集めの開始と停止 |
| POST | /api/run-now | 今すぐ候補を集める |
| GET | /api/queue | 投稿待ちの一覧 |
| PUT | /api/queue/{id} | 紹介文の書き換え |
| POST | /api/queue/{id}/images?kind=card または room | 画像を作る |
| POST | /api/queue/{id}/posted, /skip, /reopen | 投稿済みにする、見送る、元に戻す |
| GET | /api/stats | 日ごとの投稿数 |
| GET | /api/posts | 投稿の履歴 |
| GET | /api/edition | 販売モードと、使える機能 |
| POST / DELETE | /api/license | 利用キーを入れる、外す |
